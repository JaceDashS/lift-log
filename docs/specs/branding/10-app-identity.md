# App Identity
The application display name is Lift Log.

## Launcher Icon
- Two italic block L letters (LL), leaning right at about 23 degrees for a sense of speed.
- Acid #D7FF3A letters on a black #0B0D0F background. No glitch, outline or extra effect.
- The letters stay inside the adaptive icon safe zone so circle and squircle masks never cut them.
- The themed (monochrome) icon uses the same LL shape.

## Example
- Input: Installed application displayed in the launcher.
- Steps: Read the application label and icon.
- Expected result: Lift Log is displayed with acid italic LL on black.
